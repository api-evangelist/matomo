# Matomo (matomo)
Matomo is an open source web analytics platform that provides comprehensive website and application usage analytics with full data ownership. Formerly known as Piwik, it offers an alternative to Google Analytics with on-premise or cloud hosting options, ensuring complete control over analytics data and compliance with privacy regulations including GDPR.

## APIs

### Matomo Reporting API
The Matomo Reporting API provides programmatic access to all analytics reports available in the Matomo interface. It exposes over 200 API methods organized into modules such as VisitsSummary, Actions, Referrers, UserCountry, DevicesDetection, Goals, and more.

**Human URL:** [https://developer.matomo.org/api-reference/reporting-api](https://developer.matomo.org/api-reference/reporting-api)

#### Tags:

 - Analytics, Dashboards, Metrics, Reporting

#### Properties

- [Documentation](https://developer.matomo.org/api-reference/reporting-api)

### Matomo Tracking API
The Matomo Tracking API allows developers to send tracking data to Matomo from any server-side application, mobile app, or IoT device via HTTP requests. It supports pageviews, custom events, e-commerce, content interactions, site search, and bulk tracking.

**Human URL:** [https://developer.matomo.org/api-reference/tracking-api](https://developer.matomo.org/api-reference/tracking-api)

#### Tags:

 - Analytics, Events, Server-Side, Tracking

#### Properties

- [Documentation](https://developer.matomo.org/api-reference/tracking-api)

### Matomo Live API
Real-time access to visitor data including the most recent visits, visitor profiles, and live counters showing current visitors on the site.

### Matomo Goals API
Manage and retrieve data about conversion goals, including goal CRUD operations, conversion metrics, revenue data, and conversion rates.

**Human URL:** [https://developer.matomo.org/api-reference/reporting-api#Goals](https://developer.matomo.org/api-reference/reporting-api#Goals)

### Matomo Segments API
Create and manage saved segments for filtering analytics data. Any Reporting API method can accept a segment parameter to return data for a specific subset of visitors.

**Human URL:** [https://developer.matomo.org/api-reference/reporting-api-segmentation](https://developer.matomo.org/api-reference/reporting-api-segmentation)
